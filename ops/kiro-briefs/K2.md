# K2 — accessibility

**Goal:** clear the 33 accessibility violations the harness measures, by fixing their causes rather
than their symptoms.

under `wcag2a`, `wcag2aa`, `wcag21a`, `wcag21aa` and `best-practice`.

## Three causes, not three hundred nodes

1. **`landmark-one-main` and `region` are one bug.** `src/App.tsx` renders `<main className="app-main">`
   only on the branch where a scene is loaded (around line 193). The empty-state branch (around line
   178) renders `<div className="empty-state">` with an `<h2>` and a `<p>` outside any landmark. The
   first screen a judge sees therefore has no `main`. Give the empty state the same `<main>` wrapper.

2. **`color-contrast` is a token problem, not 32 separate ones.** `button.small` (`src/styles.css`
   around line 184) only sets padding and font size, so the failing pair comes from the base button
   and `.secondary` colours against their background, and from `.small` text spans using
   `--text-mid` (`#5a5a5a`) or `--text-light` (`#888`) on `--parchment`. Fix the tokens so every
   instance passes; do not special-case the selectors axe happened to name. Check both the light
   palette and the `prefers-color-scheme: dark` block (around line 46) — axe scanned one of them.

3. **`label-content-name-mismatch` is two `aria-label` strings in `src/ui/Timeline.tsx`.**
   - The cue header's label is `` `Cue: ${cue.title}. ${cueFrames.length} actions. Click to …` `` while
     the visible text says `1 action` in the singular. The accessible name must contain the visible
     text; `actions` vs `action` breaks it.
   - The action row's label is `` `Action ${kind} on ${prop}. Status: ${status}` `` while the visible
     text also includes `ID: letter-A • source-mismatch`. The visible text is not part of the name.

   Prefer letting the visible text *be* the accessible name and adding only what is not on screen,
   rather than writing a parallel sentence that has to be kept in sync.

## Paste this into Kiro

```text
Fix the accessibility violations in Ghostlight. There are three causes.

1. src/App.tsx renders <main className="app-main"> only when a scene is loaded.
   The empty-state branch renders its <h2> and <p> outside any landmark, so the
   first screen has no main landmark and its content sits outside every region.
   Put the empty state inside the same <main>. Do not add a second <main>.

2. Colour contrast fails on small buttons and small text, 32 nodes across four
   screens. button.small in src/styles.css sets only padding and font size, so
   the failure is in the base button and .secondary colours and in the
   --text-mid / --text-light tokens used by .small text on --parchment. Raise the
   tokens until every instance meets WCAG AA (4.5:1 for body text, 3:1 for large
   text). Fix the tokens, not the individual selectors axe listed. Check the
   prefers-color-scheme: dark block as well as the light one.

3. Two aria-labels in src/ui/Timeline.tsx contradict their visible text:
   - the cue header says "N actions" in its label while the row shows "1 action"
     in the singular;
   - the action row's label omits the visible secondary line ("ID: letter-A •
     source-mismatch").
   An accessible name has to contain the visible text. Rework both so the visible
   text is part of the name and the label adds only what is not on screen.

Do not change what the timeline does, only how it is named. Do not alter the
domain, the parser or any report content.

Then run npm run lint, npm run typecheck, npm test and npm run build, and report
the real results.
```

## Acceptance

- `npm run test:e2e -- --strict` passes, or any remaining violation is new, understood and written
  down with a reason.
- After the fix, re-record the baseline with `npm run test:e2e -- --record` so the file reflects
  reality, and remove the K2 note in `tests/e2e/axe-baseline.json` if it is empty.
- `npm run check` stays green: 222 tests, lint, strict typecheck, build.

## Must not change

Timeline behaviour, the domain, the parser, report contents, or the `role="tree"` structure. This is
a naming and colour pass.
