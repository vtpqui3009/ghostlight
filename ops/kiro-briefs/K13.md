# K13 — Halloween v2: make the haunted theatre unmistakable

Written 2026-11-23 by the reviewing assistant for a Kiro CLI session. Kiro writes the source;
the reviewer writes e2e tests under `tests/e2e/` and runs the checks.

## Goal

The current Halloween layer (section "The haunted theatre (K10 ...)" at the end of
`src/styles.css`) is subtle: cobweb corners, a scalloped valance, a spotlight and one 1.4 s
`lamp-up` fade. Opening the site should make a visitor say "amazing": it must read at once as a
haunted theatre at night, while every existing function, label and accessibility result stays.

## What to build

All art is inline SVG or CSS. Every decorative element has `aria-hidden="true"`, is not focusable,
has `pointer-events: none`, and sits behind content. Wrap the fixed layer in a container with
`position: fixed; inset: 0; overflow: hidden; z-index: 0` so nothing can cause horizontal scroll,
and make sure the app content (`.app-header`, `main`) sits above it (`position: relative; z-index: 1`).

1. `Decor.tsx` exports `export function Decor()` rendering one wrapper
   `<div className="haunt-decor" aria-hidden="true">` containing:
   - `.haunt-moon`: a large moon (SVG circle with soft craters and a glow), upper right.
   - `.haunt-bats`: three or four small bat silhouettes (SVG paths).
   - `.haunt-fog`: two soft fog bands near the bottom (CSS radial gradients or blurred SVG).
   - `.haunt-graves`: a row of tombstone and bare-tree silhouettes along the bottom edge (one SVG).
   Also export `GhostMascot` (a friendly cartoon ghost, SVG, `aria-hidden="true"`, class
   `haunt-ghost`) and `Pumpkin` (a jack-o-lantern, SVG, `aria-hidden="true"`, class
   `haunt-pumpkin`, with a warm inner glow).
2. `App.tsx`: render `<Decor />` as the first child of `.app`. On the first screen
   (`.first-screen`) place `<GhostMascot />` beside the "No Scene Loaded" heading and `<Pumpkin />`
   beside the featured "Start here" choice. Do not change any text, button, role, label or handler.
3. Optionally a small `<Pumpkin />` in a corner of `.stage-zones` in `StageView.tsx`, decorative only.
4. Page background is night in BOTH schemes: deep purple-black sky gradient. The light scheme's
   cards stay parchment so text contrast is unchanged.
5. Mobile (`max-width: 640px`): smaller moon, fewer/smaller bats, lighter fog, graves scaled down.
6. Small fix: in the stage List view (`.stage-list` table) on narrow screens the Role column
   wraps to many lines. Make it readable at 390 px (for example stack each row's cells, or give
   Instance and Role more width) without changing content or table semantics.

## Motion: finite only (hard rule)

The e2e harness waits for every animation to finish, so ONE infinite animation hangs the whole
suite. Never use `infinite`. Every animation has an explicit finite iteration count.

| Element | Animation | Duration, iterations |
|---|---|---|
| moon | rises from slightly lower, fades in | 1.6 s, 1 |
| bats | fly across the sky once, then fade out | about 3 s, 1 |
| fog | fades in and drifts a little | 2 s, 1 |
| first-screen curtains | the side drapes part (the inset curtain shadows can be animated, or add pseudo-element drapes) | 1.4 s, 1 |
| ghost mascot | materialises (opacity + blur + small rise) then stays still | 1.2 s, 1 |
| header title lamp | low-amplitude flicker, opacity 0.85 to 1, each cycle at least 0.5 s | 4 iterations, then steady |
| selected timeline step | candle glow that flickers | 3 iterations, each at least 0.4 s, then steady |

No more than 3 flashes per second, no large brightness jumps, no jump scares, no sound. Use
`animation-fill-mode: both` so the end state stays.

Under `@media (prefers-reduced-motion: reduce)` set `animation: none` on every K13 element: all
art stays visible in its final position, nothing moves. Under `@media print` hide `.haunt-decor`,
`.haunt-ghost` and `.haunt-pumpkin` and drop the night background.

## Accessibility (hard rules)

- Meaning never depends on the art. Keep REQUIRED / BEFORE / MATCH / MISMATCH labels, the dashed
  ghost outline, the solid block, the check/cross glyphs and all existing text exactly as they are.
- No text may sit directly on decorative art; text stays on its existing solid surfaces.
- axe-core (WCAG 2.1 A/AA + best practice) must stay at 0 violations in light and dark, including
  with a failing timeline step selected. Text directly on the page background (if any) must have
  at least 4.5:1 contrast against the darkest and lightest part of the night gradient.
- No horizontal overflow at 390 px on the first screen, stage, list, reports and editor.
